Bu web repo'suna ikinci bir veresiye veri modeli kurulmamıştır. Gerekli erişim kayıtları ve rate-limit tablosu, mevcut Yunus ProPOS veritabanına additive migration olarak uygulanmıştır. Kaynak migration ProPOS repo'sunda `src/supabase/migrations/20261125082110_veresiye_portal_access_control.sql` konumundadır. Mevcut ProPOS `customers`, `sales`, `sale_items`, `sale_payments`, `customer_payments` veya `sale_returns` tabloları kopyalanmaz.
